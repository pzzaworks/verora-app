The deploy script writes one manifest per chain to `verora-contracts/deployments/<chainId>.json`. Load it
with `parseDeployment` in the SDK, or copy the addresses into the API and app environment.

Indexers start reading events at block `11900598`, the block the contracts were deployed in.

Point the app at this network with:

```bash title=".env.local"
NEXT_PUBLIC_CHAIN=sepolia
NEXT_PUBLIC_API_URL=https://api.veroraprotocol.com
NEXT_PUBLIC_AGENT_REGISTRY_ADDRESS=0x701A2a74fcc92b3310c5F9c9Fc2dd03c3C6e45cc
NEXT_PUBLIC_QUERY_CONSUMER_ADDRESS=0x359b07841C0Add13533D0032187E865290828Cd2
NEXT_PUBLIC_STAKING_POOL_ADDRESS=0xD60936Bc2E8653340A43Cf711Bd04b3d894B945f
NEXT_PUBLIC_REPUTATION_MANAGER_ADDRESS=0x390833B00F624d281a10D82F0139E8004f5A428B
NEXT_PUBLIC_PAYMENT_ROUTER_ADDRESS=0x8552f8eb6cbAb35B3e917d17fAa6CCac34f595a8
```

Mainnet requires an external security audit first.

## Local (Anvil, chain 31337)

the default deployer (Anvil account 0). Because the deployer and its nonce are the same on every fresh
